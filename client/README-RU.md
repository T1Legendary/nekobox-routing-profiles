# NekoBox 5.11.24 WEPPi — простые правила маршрутизации

Сборка исправляет импорт JSON и обновление профилей через штатное меню NekoBox.
Основа: qr243vbi/nekobox, тег 5.11.24, коммит 2dbdb5f6f61efe9830808c44876bfd82b6b5cc9a.
Версия сборки: 5.11.24-weppi-routing-1. Windows x64.

## Поведение

* Правила только с domain/domain_suffix/domain_keyword/domain_regex/ip_cidr/rule_set получают тип Simple Address.
* Правила только с process_name — Simple Process Name; только с process_path — Simple Process Path.
* Поддерживаются направления direct/proxy/block и обычное action: reject.
* Правила с портами, инверсией, протоколом, сочетанием адреса и процесса, неизвестными полями или дополнительными параметрами остаются custom.
* Меняются только метаданные интерфейса: type, simple_action, name. Условия, действие, outbound и порядок правил при импорте сохраняются.
* Простые правила видны в «Основных маршрутах». Открытие окна и OK без изменений не пересобирают их. Ручное изменение соответствующего столбца использует штатное поведение редактора NekoBox с перегруппировкой правил этого направления.
* Обновление через меню сохраняет профиль на диск. При ошибке сохранения остаётся прежний профиль в памяти, а ошибка записывается в журнал.
* Ссылки raw.githubusercontent.com загружаются напрямую из GitHub.

JSON-файлы profiles/*.json и catalog.json менять ради отображения не требуется.
После однократной установки этой сборки обычные изменения профилей выполняются через меню клиента.
Проверка коммита и кэш профилей в серверном установщике остаются отдельным механизмом.
Штатная кнопка обновления самого приложения скрыта, чтобы случайно не заменить эту сборку оригинальной.
Скачивание/обновление профилей через меню остаётся включённым.

## Сборка и проверка

Workflow `.github/workflows/build-simple-routing.yml` запускается при изменениях client/ в ветке weppi-client/simple-routing-v1.
Он проверяет 82 случая классификации, собирает C++ интерфейс, сохраняет оригинальное ядро из архива 5.11.24 с проверкой SHA-256, развёртывает полный комплект DLL и проверяет запуск GUI без подключения VPN.
Готовые файлы — в артефакте GitHub Actions: установщик, portable ZIP, архив исходников и build-manifest.json с контрольными суммами.
Workflow ничего не публикует в Releases и не устанавливает на VPS.

Локальная проверка классификатора (Linux, из каталога с исходниками после применения патча):

```sh
g++ -std=c++20 -Wall -Wextra -Werror -Isrc /path/to/client/tests/simple_rules_test.cpp -o /tmp/simple-rules-test
/tmp/simple-rules-test
```

Для Windows использовать MSVC 2022 x64, Qt 6.10.0, Ninja, CMake и NSIS.
Точные версии исходников vcpkg и GitHub Actions закреплены SHA в workflow.
Полный Qt-комплект входит в ZIP: одиночный EXE нельзя смешивать с DLL другой сборки.
Перед обновлением существующей установки закрыть NekoBox и сохранить копию всей его папки.
Папки settings, notes и пользовательские public-скрипты должны сохраняться при обновлении клиента.
Установщик предназначен для новой установки; обновление существующей персональной установки выполняется отдельно после проверки сборки.
